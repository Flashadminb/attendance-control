# Attendance Control — คู่มือติดตั้งและใช้งาน

## ไฟล์ในระบบ
| ไฟล์ | ใช้ทำอะไร |
| --- | --- |
| `Attendance Admin.dc.html` | หลังบ้าน: อัปโหลด ตั้งค่ากฎ ตั้งค่ากะ เกณฑ์หนังสือเตือน Export & Sync |
| `Attendance Viewer.dc.html` | หน้างาน: ดูอย่างเดียว ดึงข้อมูลส่วนกลางอัตโนมัติ |

| `google-apps-script.gs` | ตัวกลางเชื่อม Google Sheet |

## ขั้นที่ 1 — ติดตั้ง Apps Script (ทำครั้งเดียว)
1. เปิดชีตปลายทาง → **Extensions → Apps Script**
2. วางเนื้อหาไฟล์ `google-apps-script.gs` ทับ Code.gs
3. แก้บรรทัด `var TOKEN = 'CHANGE-ME-1234';` เป็นรหัสของคุณเอง → Save
4. **Deploy → New deployment → Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
5. คัดลอก **Web app URL** (ลงท้าย `/exec`)

> แก้ไฟล์ .gs ทีหลังทุกครั้ง ต้อง Deploy → Manage deployments → Edit → Version: **New**

## ขั้นที่ 2 — นำเว็บขึ้น GitHub Pages
```
git init && git add . && git commit -m "attendance control"
git branch -M main
git remote add origin https://github.com/<user>/<repo>.git
git push -u origin main
```
แล้วไปที่ repo → **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main / (root)** → Save
ได้ลิงก์ `https://<user>.github.io/<repo>/Attendance%20Viewer.dc.html` ส่งให้หน้างาน
และ `.../Attendance%20Admin.dc.html` เก็บไว้ใช้เอง

## ขั้นที่ 3 — ตั้งค่าครั้งแรก
- **แอดมิน**: เปิดหน้า Export & Sync → วาง Web app URL + TOKEN (ตรงกับที่ตั้งใน .gs)
- **หน้างาน**: เปิด Viewer → วาง Web app URL ในช่อง "ข้อมูลส่วนกลาง" ที่แถบซ้ายล่าง (ครั้งเดียว จำไว้ให้)

## งานประจำวันของแอดมิน (2 นาที)
1. เมนู 01 อัปโหลดไฟล์ → ลากไฟล์ **attendance** ลงกล่องซ้าย
   **ตารางกะไม่ต้องอัปทุกวัน** — ระบบจำไฟล์ล่าสุดไว้ให้ อัปใหม่เฉพาะตอนมีพนักงานใหม่หรือเปลี่ยนกะ
   (วันที่ไฟล์ตารางกะไม่ครอบคลุม ระบบใช้ "กะประจำตัว" ของแต่ละคนแทน โดยข้ามวันที่ลงว่าหยุด/ลาไว้แล้ว)
2. ตรวจแดชบอร์ด → ติ๊ก "ส่งแล้ว" ให้คนที่ออกหนังสือเตือนไปแล้ว
3. ไปหน้า Export & Sync → เลือกช่วงวันที่ → กด **Sync ตอนนี้**
4. หน้างานทุกเครื่องเห็นข้อมูลใหม่ทันทีที่เปิดหรือกด "ดึงข้อมูลล่าสุด" (รีเฟรชเองทุก 5 นาที)

> ข้อมูลเดือนเก่าไม่หาย — อัปเดือนใหม่แล้วเดือนก่อนยังอยู่ (เก็บ 15 เดือนในเครื่อง / 24 เดือนบนชีต) สลับดูได้ที่ช่องเลือกเดือนมุมขวาบน

## เริ่มใหม่ทั้งหมด
เมนู **01 อัปโหลดไฟล์** มี 2 ปุ่ม
- **ล้างไฟล์ที่เพิ่งอัป** — เอาไฟล์ที่ค้างอยู่ออกจากหน้าจอ ข้อมูลที่เก็บไว้ยังอยู่ครบ
- **ลบข้อมูลทั้งหมดในเครื่อง** — ลบข้อมูลรายเดือน คลังสถิติ ประวัติหนังสือเตือน กฎ รหัสที่เพิ่มเอง และตารางกะที่จำไว้ (ถามยืนยันก่อน กู้คืนไม่ได้)

> ข้อมูลเก็บแยกตามเบราว์เซอร์และแยกตามลิงก์ — ปุ่มนี้ลบเฉพาะเครื่องที่กด
> ไฟล์ต้นฉบับใน HCM และข้อมูลบน Google Sheet ไม่ได้รับผลกระทบ

## สั่งล้างข้อมูลทุกเครื่องพร้อมกัน
แอปเก็บข้อมูลไว้ในเครื่องของแต่ละคน ไม่มีเซิร์ฟเวอร์กลางให้กดลบทีเดียวจบ จึงใช้ "เลขรุ่นข้อมูล" แทน

แก้บรรทัดนี้ในทั้ง `Attendance Admin.dc.html` และ `Attendance Viewer.dc.html` ให้เป็นค่าใหม่ (ต้องตรงกันทั้งสองไฟล์)

```
DATA_VERSION = '2026-08-05-reset-1';
```

แล้ว push ขึ้น GitHub — เครื่องไหนเปิดเว็บครั้งถัดไปจะเห็นว่าเลขไม่ตรงกับที่ตัวเองจำไว้ แล้วล้างข้อมูลตัวเองทิ้งอัตโนมัติ พร้อมขึ้นข้อความในบันทึกการประมวลผล

> มีผลกับทุกเครื่องทุกคน แต่ต้องรอให้เครื่องนั้นเปิดเว็บก่อน — เครื่องที่ไม่เปิดจะยังมีข้อมูลเก่าค้างอยู่
> ฝั่งหน้างานจะเก็บ URL ส่วนกลางไว้ให้ ไม่ต้องวางใหม่

## อ่านสีในตาราง
| สี | ความหมาย | ตัวย่อ |
| --- | --- | --- |
| แดง | ขาดงาน / ไม่แสกน / ไม่มีกะ / แสกนไม่ครบ / ตั้งกะในวันหยุดแต่ไม่แสกน | AB, NS, NoS, INC, OFF! |
| เหลือง | มาสาย หรือ ออกก่อนเวลา (เกิน grace) | L15, E20 |
| เทา | ลาเต็มวัน / วันหยุดประจำสัปดาห์ / วันหยุดนักขัตฤกษ์ | AL, SL, PL, UL, ML, OFF, PH |
| เทาอ่อน | ลาครึ่งวัน | AL½ |
| ทแยงสองสี | วันเดียวมีสองสถานะ เช่น ลาครึ่งวัน + สาย | AL½·L6 |

ต่อท้าย **?** = รอการอนุมัติ

## ตัวเลขสองตัวที่ต้องแยกให้ออก
- **Attendance Rate** = คนที่มีการแสกนในวันนั้น ÷ พนักงานทั้งหมด (ตัวหารรวมวันหยุด) — สูตรเดียวกับชีต HCM เดิม `=I69/$B$69`
- **อัตราตรงเวลา** = (วันปกติ + วันลาที่อนุมัติ) ÷ วันทำงาน โดยตัดวันหยุด/PH ออกจากตัวหาร

## แสกนไม่ครบ (INC) กับการยื่นย้อนหลัง
- วันที่แสกนไม่ครบ (มีแค่ in หรือ out) **ถูกคิดเป็นขาดงาน** ในการคำนวณ Attendance Rate เพราะยังพิสูจน์การมาทำงานไม่ได้
- แต่ในตารางยัง **โชว์รหัส `INC` สีแดงตามเดิม** ไม่เปลี่ยนเป็น `AB` — จะได้แยกออกว่าเป็นคนละเคสกัน
- **ลาครึ่งวันนับเป็นมาทำงาน** ถ้าครึ่งที่ต้องทำงานแสกนครบ (มาสายก็ยังนับว่ามา) · ถ้าครึ่งนั้นแสกนไม่ครบหรือไม่แสกนเลย = ขาดงาน (เห็นเป็นช่องทแยง `AL½` เทาอ่อน+แดง)
- พนักงานที่ลืมแสกนแล้ว**ยื่นย้อนหลังจนอนุมัติ** ระบบ HCM จะส่งเวลาเข้า-ออกครบในไฟล์รอบถัดไป
  แอดมินแค่อัปโหลดไฟล์ทับเดือนเดิม → สถานะเปลี่ยนเป็นมาทำงานเองอัตโนมัติ ทั้งสีในตารางและเปอร์เซ็นต์
  (ข้อมูลเดือนนั้นถูกเขียนทับทั้งชุด ไม่ต้องลบของเก่าก่อน และการติ๊ก "ส่งแล้ว" ของหนังสือเตือนไม่หาย)

## เกณฑ์หนังสือเตือน — ตั้งกฎเองได้
หน้า **09 ตั้งค่ากฎสี** → หัวข้อ "กฎหนังสือเตือน" เพิ่ม/แก้/ลบกฎได้อิสระ แต่ละกฎคือ

> ตัวชี้วัด ≥ ค่า → ใบเตือนระดับนี้

ตัวชี้วัดที่เลือกได้: ขาดงาน (วัน) · มาสาย (ครั้ง) · นาทีสายรวม · **สายครั้งเดียวเกิน N นาที** · แสกนไม่ครบ · ออกก่อนเวลา
ช่อง "ความรุนแรง" เป็นตัวเลข — ใครเข้าหลายกฎจะได้ระดับของกฎที่เลขสูงสุด และตารางจะบอกด้วยว่าเข้ากฎข้อไหน

ค่าเริ่มต้น: ขาด ≥ 3 วัน / สาย ≥ 5 ครั้ง / สายครั้งเดียวเกิน 120 นาที → เตือนครั้งที่ 1 · ขาด ≥ 6 วัน / สาย ≥ 10 ครั้ง → เตือนครั้งที่ 2

**รอบนับ**: รายเดือน (จบเดือนรีเซ็ต) · รายปี · ย้อนหลัง N วัน

## เพิ่มรหัสเองเมื่อ HCM ส่งคำใหม่มา
หน้า **09** → หัวข้อ "รหัสที่เพิ่มเอง" — ใส่คำที่พบในช่อง แล้วกำหนดรหัส/สี/ว่านับเป็นมาทำงานไหม
กฎที่เพิ่มเองมาก่อนกฎมาตรฐานเสมอ และหลังอัปไฟล์ ระบบจะ**เสนอคำที่มันยังอ่านไม่ออกให้อัตโนมัติ** กดเพิ่มได้เลย
