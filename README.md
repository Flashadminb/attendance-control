## ข้อมูลอยู่ที่ไหน
**ชีตเป็นต้นฉบับที่เดียว** — เว็บไม่เก็บข้อมูลพนักงานไว้ในเครื่องใครเลย

```
ไฟล์ HCM  →  เว็บแกะไฟล์  →  ให้ตรวจก่อน  →  เขียนลงชีต  →  ทุกคนอ่านจากชีต
```

คนที่อัปก็อ่านจากชีตเหมือนคนอื่น ไม่ได้ดูของที่ตัวเองเพิ่งคำนวณ เขียนไม่ครบเมื่อไหร่จึงเห็นทันทีตั้งแต่ตอนอัป

ในเครื่องเหลือเก็บแค่ 3 อย่างที่ไม่ใช่ข้อมูลรายคน: การล็อกอิน · คลังสถิติย้อนหลัง (ตัวเลขสรุป) · กฎกับรหัสที่ตั้งเอง

> **แก้แถวในแท็บ Matrix ด้วยมือไม่มีผลกับหน้าเว็บ** — เว็บอ่านจากแท็บซ่อนชื่อ `_data`
> จะแก้ของเก่าให้ **อัปไฟล์เดือนนั้นทับ** หรือกด **ลบข้อมูลเดือนนี้ออกจากชีต**

## ขั้นที่ 1 — ติดตั้ง Apps Script (ทำครั้งเดียว)
1. เปิดชีตหลัก → **Extensions → Apps Script**
2. วางเนื้อหาไฟล์ `google-apps-script.gs` ทับ Code.gs → Save
3. **Deploy → New deployment → Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
4. คัดลอก **Web app URL** (ลงท้าย `/exec`) ไปใส่ใน `config.js`

> ไม่ต้องตั้งรหัสอะไรเพิ่ม ระบบใช้การล็อกอินแอดมินยืนยันตัวให้เอง
> แก้ไฟล์ .gs ทีหลังทุกครั้ง ต้อง Deploy → Manage deployments → Edit → Version: **New**

## ขั้นที่ 2 — รายชื่อผู้ใช้
สร้างแท็บชื่อ **DATA** ในชีตผู้ใช้ เรียงคอลัมน์ตามนี้

| A | B | C | D | E |
| --- | --- | --- | --- | --- |
| ชื่อ | ยูสเซอร์ | รหัส | กะที่ดูแล | เมนูที่เข้าได้ |

- **กะที่ดูแล** ใส่ชื่อกะให้ตรงกับที่ตั้งไว้ในเว็บ เช่น `03:00-12:00, 18:00-03:00` · ใส่ `ทั้งหมด` = เห็นทุกกะ
- **เมนูที่เข้าได้** เว้นว่าง = ได้เมนูมาตรฐานของหน้างาน (แดชบอร์ด · ตารางสี · รายพนักงาน · หนังสือเตือน · คลังสถิติ · ส่งออก) — ไม่รวม "รายตำแหน่ง" เพราะเป็นภาพรวมข้ามทั้งฮับ ถ้าอยากให้ใครเห็นให้ใส่คำว่า `hub` ลงในช่องนี้
- เพิ่ม/ลบผู้ใช้จากหน้า **09 ผู้ใช้และสิทธิ์** ในเว็บก็ได้ ไม่ต้องมาแก้ในชีต

## งานประจำวันของแอดมิน
1. เมนู **01 อัปโหลดไฟล์** → ลากไฟล์ **attendance** ลงกล่องซ้าย
   **ตารางกะไม่ต้องอัปทุกวัน** — ระบบจำไฟล์ล่าสุดไว้บนชีต อัปใหม่เฉพาะตอนมีพนักงานใหม่หรือเปลี่ยนกะ
2. อ่าน **หน้าตรวจก่อนเขียน** ที่ขึ้นมา — ยังไม่มีอะไรถูกแก้ในจังหวะนี้
   - จำนวนคนในไฟล์ เทียบกับที่มีบนชีต
   - **คนที่ไม่เคยอยู่บนชีต** — ถ้าเจอชื่อที่ไม่ใช่พนักงานเรา แปลว่าหยิบไฟล์ผิด กดยกเลิก
   - **คนที่ไม่มีในไฟล์นี้** — จะถูกตัดออกจากชีตของช่วงวันที่นี้
   - แถบเหลือง/แดง = ระบบสงสัยว่าผิด แดงต้องกดยืนยันซ้ำอีกชั้น
3. กด **ยืนยัน เขียนลงชีต**
4. ทุกคนที่เปิดเว็บอยู่จะเห็นชุดใหม่ภายใน 2 นาที หรือกด **ดึงข้อมูลจากชีต** ที่แถบซ้ายล่างเอง

> เผลออัปผิด กด **ย้อนการอัปล่าสุด** ได้ ย้อนได้รอบเดียวและกดจากเครื่องไหนก็ได้

## ลบข้อมูล
เมนู **01 อัปโหลดไฟล์** ด้านล่าง
- **ลบข้อมูลเดือนนี้ออกจากชีต** — ลบทั้งเดือน รวมถึงวันของเดือนนั้นในชีตสำรอง
- **ลบข้อมูลทั้งหมด** — ล้างทุกเดือน ตารางที่คนอ่านได้ ชีตสำรองรายปี ตารางกะที่จำไว้ และของในเครื่องนี้

> กู้คืนไม่ได้ — แต่ไฟล์ต้นฉบับใน HCM ไม่ได้รับผลกระทบ อัปใหม่ได้ตลอด

## อ่านสีในตาราง
| สี | ความหมาย | ตัวย่อ |
| --- | --- | --- |
| แดง | ขาดงาน / ไม่แสกน / ไม่มีกะ / แสกนไม่ครบ / ตั้งกะในวันหยุดแต่ไม่แสกน | AB, NS, NoS, INC, OFF! |
| เหลือง | มาสาย หรือ ออกก่อนเวลา (เกิน grace) | L15, E20 |
| เทา | ลาเต็มวัน / วันหยุดประจำสัปดาห์ / วันหยุดนักขัตฤกษ์ | AL, SL, PL, UL, ML, OFF, PH |
| เทาอ่อน | ลาครึ่งวัน | AL½ |
| ทแยงสองสี | วันเดียวมีสองสถานะ เช่น ลาครึ่งวัน + สาย | AL½·L6 |

ต่อท้าย **?** = รอการอนุมัติ

## ตัวเลขสองตัวที่ต้องแยกให้ออก
- **Attendance Rate** = คนที่มีการแสกนในวันนั้น ÷ พนักงานทั้งหมด (ตัวหารรวมวันหยุด) — สูตรเดียวกับชีต HCM เดิม `=I69/$B$69`
- **อัตราตรงเวลา** = (วันปกติ + วันลาที่อนุมัติ) ÷ วันทำงาน โดยตัดวันหยุด/PH ออกจากตัวหาร

## แสกนไม่ครบ (INC) กับการยื่นย้อนหลัง
- วันที่แสกนไม่ครบ (มีแค่ in หรือ out) **ถูกคิดเป็นขาดงาน** ในการคำนวณ Attendance Rate เพราะยังพิสูจน์การมาทำงานไม่ได้
- แต่ในตารางยัง **โชว์รหัส `INC` สีแดงตามเดิม** ไม่เปลี่ยนเป็น `AB` — จะได้แยกออกว่าเป็นคนละเคสกัน
- **ลาครึ่งวันนับเป็นมาทำงาน** ถ้าครึ่งที่ต้องทำงานแสกนครบ (มาสายก็ยังนับว่ามา) · ถ้าครึ่งนั้นแสกนไม่ครบหรือไม่แสกนเลย = ขาดงาน (เห็นเป็นช่องทแยง `AL½` เทาอ่อน+แดง)
- พนักงานที่ลืมแสกนแล้ว**ยื่นย้อนหลังจนอนุมัติ** ระบบ HCM จะส่งเวลาเข้า-ออกครบในไฟล์รอบถัดไป
  แอดมินแค่อัปโหลดไฟล์ทับเดือนเดิม → สถานะเปลี่ยนเป็นมาทำงานเองอัตโนมัติ ทั้งสีในตารางและเปอร์เซ็นต์
  (ข้อมูลเดือนนั้นถูกเขียนทับทั้งชุด ไม่ต้องลบของเก่าก่อน และการติ๊ก "ส่งแล้ว" ของหนังสือเตือนไม่หาย)

## เกณฑ์หนังสือเตือน — ตั้งกฎเองได้
หน้า **08 ตั้งค่ากฎสี** → หัวข้อ "กฎหนังสือเตือน" เพิ่ม/แก้/ลบกฎได้อิสระ แต่ละกฎคือ

> ตัวชี้วัด ≥ ค่า → ใบเตือนระดับนี้

ตัวชี้วัดที่เลือกได้: ขาดงาน (วัน) · มาสาย (ครั้ง) · นาทีสายรวม · **สายครั้งเดียวเกิน N นาที** · แสกนไม่ครบ · ออกก่อนเวลา
ช่อง "ความรุนแรง" เป็นตัวเลข — ใครเข้าหลายกฎจะได้ระดับของกฎที่เลขสูงสุด และตารางจะบอกด้วยว่าเข้ากฎข้อไหน

ค่าเริ่มต้น: ขาด ≥ 3 วัน / สาย ≥ 5 ครั้ง / สายครั้งเดียวเกิน 120 นาที → เตือนครั้งที่ 1 · ขาด ≥ 6 วัน / สาย ≥ 10 ครั้ง → เตือนครั้งที่ 2

**รอบนับ**: รายเดือน (จบเดือนรีเซ็ต) · รายปี · ย้อนหลัง N วัน

## เพิ่มรหัสเองเมื่อ HCM ส่งคำใหม่มา
หน้า **08** → หัวข้อ "รหัสที่เพิ่มเอง" — ใส่คำที่พบในช่อง แล้วกำหนดรหัส/สี/ว่านับเป็นมาทำงานไหม
กฎที่เพิ่มเองมาก่อนกฎมาตรฐานเสมอ และหลังอัปไฟล์ ระบบจะ**เสนอคำที่มันยังอ่านไม่ออกให้อัตโนมัติ** กดเพิ่มได้เลย
